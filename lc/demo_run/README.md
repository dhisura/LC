# Password Generator

This repository contains a simple password generator and its unit tests.

## Usage

- `password_gen.py` is the main script for generating passwords.
- `test_password_gen.py` contains unit tests for `password_gen.py`.

## How to Run

1. Run `password_gen.py` with the desired length and character sets.
2. Run `test_password_gen.py` to ensure the script works as expected.

## Example

python password_gen.py --length 16 --include_uppercase --include_lowercase --include_numbers --include_symbols

## Documentation

- `password_gen.py` includes docstrings for each function.
- `test_password_gen.py` includes docstrings for each test method.
